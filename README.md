# 知乎 · Kindle 下载

这是安卓 App「知乎 · Kindle」的下载仓库。App 能把知乎上挑好的文章做成一本电子书，一键交给 Kindle App 发到 Kindle。

- 每个版本是一个 Release，附件里有安装包 `Kindle-Zhihu.apk` 和这一版对应的完整源码。
- Release 说明里写了这一版更新了什么，以及安装包的 SHA-256 校验码。

本 App 基于开源项目 [Zhihu++](https://github.com/zly2006/zhihu-plus-plus)（AGPL-3.0）修改，同样以 AGPL-3.0 发布，源码见每个 Release 的附件。本 App 与知乎官方无关。
